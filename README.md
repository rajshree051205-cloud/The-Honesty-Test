# The Honesty Test 🧠

An interactive and fun web-based personality test built using HTML, CSS, and JavaScript that analyzes user input through age-based and honesty-style responses with engaging messages.

## Live Demo
Try it here: https://rajshree051205-cloud.github.io/The-Honesty-Test/

## Features
- Interactive honesty/personality test experience
- Dynamic age/category-based responses
- Fun and engaging custom messages
- User input validation
- Clean and responsive UI
- Beginner-friendly frontend project
- Real-time result display

## Tech Stack
- HTML5
- CSS3
- JavaScript

## Project Purpose
This project was created for fun while improving frontend web development skills through DOM manipulation, conditional logic, and interactive UI design.

## What I Learned
- DOM manipulation
- Conditional statements
- User input handling
- Dynamic content updates
- Responsive styling
- Creative UI/UX experimentation

## How It Works
1. User enters details/input
2. JavaScript processes conditions
3. Personalized honesty/fun response is displayed instantly
